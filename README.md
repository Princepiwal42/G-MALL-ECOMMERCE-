📊 G-Mall Ecommerce Dashboard – Power BI Project
🔎 Project Overview

The G-Mall Ecommerce Dashboard is an interactive business intelligence solution built using Microsoft Power BI to analyze and visualize ecommerce sales performance.

This dashboard provides a comprehensive overview of key business metrics including revenue, profit, quantity sold, customer performance, product profitability, and regional insights.

Designed with a modern dark-themed UI and dynamic filters, the dashboard enables stakeholders to monitor performance trends and make data-driven decisions efficiently.
